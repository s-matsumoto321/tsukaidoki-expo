このプロトで実装したこと

STATE A：通常表示

使いみち画面のメイン状態。グラフから凡例を削除（下のカードが凡例代わり）。各カードからも積立金額の固定表記を削除（期間で変わるため）。

STATE B：モーダル · 通常状態

「積立を調整する」を押すと、モーダルが画面下から半分まで立ち上がる。期間は折りたたまれた1行の状態で、「2026〜2059 / 期間を選ぶ ›」と表示。ユーザーが期間を変える必要がない時は、4つの使いみちの+/-にすぐアクセスできる。

STATE C：モーダル · 期間展開（核心）

「期間を選ぶ ›」をタップすると、モーダルが上に拡大（50% → 78%）し、期間セクション内に 俯瞰の積み上げグラフ が展開する。

  • 積み上げ面グラフ：横軸に時間、縦軸に月額（0〜10万）。下から教育・老後・車・旅行の積立配分が積み上がる。期間ごとに段差ができるので、「いつ何をどう振り分けてきたか」の歴史が一目で見える。
  • 上限ライン：上端に「上限 月10万」の点線。①で決めた限度額がここに表れる。
  • 年齢軸：横軸の下に4行（年・あなた・妻・子）。「子供が5歳の時はあなたが何歳か」が一覧できる。選択範囲内の子供の年齢には緑のマーカー。
  • 範囲スライダー：From-Toを2つのつまみで指定。グラフ上には選択範囲が緑の半透明帯でハイライトされる。

操作の流れ

  1. 「積立を調整する」をタップ → STATE B
  2. 「期間を選ぶ ›」をタップ → STATE C（モーダルが上に拡大）
  3. 年齢軸を見ながら、スライダーで「子供3〜5歳」を範囲指定（2028〜2030年）
  4. 下に並ぶ使いみちの+/-で、その期間の配分を調整
  5. 後ろの推移グラフが連動して動く（赤字の解消が見える）
  6. 確定したら期間を閉じて、別の期間を編集できる
この設計の核：「期間」と「俯瞰」と「年齢」を、すべて1つのモーダル内で完結させた。別画面に飛ばないので、調整中の文脈が失われない。
特に俯瞰の積み上げグラフは、「2028〜2032を修正したい時、今そこに何を積み立てているか」という問いに直接答える。各使いみちの色が、上のメイン推移グラフと一致しているので、認知の負担も少ない。

実装上の注意点

  • モーダルの高さ変化（50%↔78%）はアニメーションで滑らかに。
  • 俯瞰グラフは情報密度が高いので、レンダリングはシンプルに保つ（タップしたセグメントの詳細は出さず、グラフは見るだけ）。
  • 期間スライダーのつまみは、年単位でスナップする（半端な月にならない）。
  • 家族の年齢データは、設定画面で家族構成として登録する前提（v3で残された議論ポイント）。
